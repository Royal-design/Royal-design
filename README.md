## 👨‍💻 About Me

I'm a **Full Stack Engineer with a strong frontend focus**, passionate about transforming ideas into polished digital experiences.

My expertise lies in building scalable frontend architectures while also developing robust backend APIs and services.

- 💻 Built production-ready applications using **React, Next.js, TypeScript, and modern frontend ecosystems**.
- 📱 Building cross-platform mobile applications with **React Native and Expo**.
- ⚙️ Developing scalable backend APIs using **Node.js, Express.js, NestJS, and FastAPI**.
- 🗄️ Experienced with **PostgreSQL, MongoDB, Firebase, and database design**.
- 🔐 Strong understanding of **authentication, authorization, API integration, and state management**.
- 🧩 Passionate about **clean architecture, reusable components, accessibility, and performance optimization**.
- 🚀 Continuously learning and exploring modern web technologies and software engineering best practices.
